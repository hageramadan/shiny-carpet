# Shiny Carpet — Shiny Carpet

مشروع مستقل لتصميم موقع غسيل السجاد والبطاطين، عربي RTL باستخدام Next.js App Router وTypeScript وTailwind CSS وreact-icons وخط Cairo محلي.

## التشغيل

```sh
npm install
npm run dev
```

المعاينة: http://localhost:3000. على Windows يمكن تشغيل start-dev.cmd مباشرة بعد تثبيت المكتبات. لو أمر npm غير متاح استخدم: node node_modules/next/dist/bin/next dev --port 3000

```sh
npm run typecheck
npm run build
npm start
```

## تقسيم الملفات

- app/: الصفحات وبيانات SEO وملف CSS الرئيسي.
- components/: shell للهيدر والفوتر، store للبيانات الة، shop للخدمات والسلة، account للحساب والعناوين، orders لإتمام الطلب والتتبع، ui لعناصر مشتركة بسيطة.
- lib/data.ts: الأنواع المشتركة وبيانات قديمة لدعم السجلات المحلية؛ lib/api-products.ts: جلب المنتجات والتحقق منها.
- public/: الصور وملفات خط Cairo.

## البيانات الة

السلة والعناوين والملف الشخصي والطلبات محفوظة في localStorage على نفس المتصفح. الدخول شكلي فقط، لا توجد مصادقة أو دفع أو إشعارات فعلية. التحقق بالهاتف معاينة فقط ولا تُرسل رسائل SMS. قسم خدماتنا يجلب التصنيفات وصورها من API شايني كاربت، وخدمة البحث عن الأماكن توفر البحث الخاص بالعناوين. استخدم بيانات وهمية أثناء المعاينة. أسعار المنتجات الحالية من API، والطلبات محلية للمعاينة والتتبع توضيحي لحين ربط إنشاء الطلبات. لا توجد تقييمات أو أرقام عملاء وهمية.

## SEO قبل النشر

عناوين وأوصاف صفحات الخدمة مع canonical وOpen Graph وTwitter، HTML عربي على الخادم وsitemap.xml وrobots.txt. صفحات الحساب والشراء والتتبع مستبعدة من الفهرسة. انسخ .env.example إلى .env.local وغيّر NEXT_PUBLIC_SITE_URL للدومين الحقيقي قبل البناء والنشر. ترتيب البحث يعتمد على المحتوى الحقيقي والدومين والأداء والربط؛ لا توجد ضمانات ترتيب.

## الربط لاحقًا

استبدل localStorage في components/store.tsx بمصدر بيانات حقيقي، وأضف المصادقة والتحقق من الأسعار والمقاسات ومواعيد الخدمة على الخادم. ملف data.ts يحتفظ ببيانات النسخة القديمة بالجنيه المصري لدعم السجلات المحلية السابقة؛ المنتجات الحالية من API وتعرض بالريال السعودي.

## العناوين والخريطة

العناوين في `/addresses`، والإضافة في `/addresses/new`، والتعديل في `/addresses/[id]/edit`. يتم حفظ الإحداثيات وتفاصيل المبنى والدور والشقة محليًا، مع دعم السجلات القديمة. العنوان الافتراضي يُستخدم في الملف الشخصي وإتمام الطلب، وحذفه يعيّن أول عنوان متبقٍ افتراضيًا؛ لا تتغير عناوين الطلبات السابقة.

الخريطة تستخدم Leaflet وبيانات OpenStreetMap، والبحث عبر Photon من مسار `/api/locations`. البحث يحدث عند الضغط على زر البحث، وتُخزّن نتائجه مؤقتًا مع تقليل معدل الطلبات. يمكن تغيير خادم Photon عبر `GEOCODING_BASE_URL`. الخادم العام مناسب للمعاينة محدودة الاستخدام ولا يضمن التوافر: https://github.com/komoot/photon#demo-server. استخدام خرائط OpenStreetMap يخضع لسياسة البلاطات: https://operations.osmfoundation.org/policies/tiles/.

الموقع الحالي يحتاج إذن المتصفح، ويعمل عبر HTTPS أو localhost. لا يُطلب الموقع تلقائيًا؛ يمكن البحث عن أي مكان أو اختيار نقطة وسحب العلامة. راجع تفاصيل العنوان المقترحة قبل الحفظ، خصوصًا رقم المبنى والدور والشقة. هذه واجهة ة؛ لا تُنشئ طلب توصيل حقيقيًا.

## API الخدمات والمنتجات

قسم خدماتنا وقائمة المنتجات يجلبان البيانات مباشرة من المتصفح، لذلك تظهر الطلبات في Network → Fetch/XHR:

- GET https://admin.shinycarpet-sa.com/api/categories
- GET https://admin.shinycarpet-sa.com/api/products/category/{categoryId}
- GET https://admin.shinycarpet-sa.com/api/products/{productId}

روابط التصنيفات: /products?category=16. تفاصيل المنتج: /products/20، وتجلب بياناته مباشرة من واجهة تفاصيل المنتج. الروابط القديمة /products/carpet و/products/blanket توجه إلى التصنيف المناسب. يتم التحقق من الاستجابة ومعرف التصنيف والأسعار قبل العرض، مع حالات تحميل وقائمة فارغة وخطأ وإعادة المحاولة. الصور الخارجية مسموحة فقط من مساري /storage/categories/ و/storage/products/ على نطاق الإدارة.

أسعار المقاسات المحددة تؤخذ مباشرة من price_before_discount (أو price_after_discount للمقاس عند توفر خصم صريح)، ولا تضرب في المساحة مرة ثانية. إذا كان has_sizes=1 دون قائمة مقاسات ومع وجود price_per_unit، يظهر إدخال أبعاد بالمتر وتحسب المساحة بالسعر المعلن. المنتجات ذات has_sizes=0 تستخدم price وتتحسب بالكمية. الأسعار الحالية تعرض بالريال السعودي، وتظل السجلات التجريبية السابقة بالجنيه المصري؛ لا يسمح بخلط العملتين في سلة واحدة.

السلة تحفظ نسخة المنتج والمقاس والسعر المختار للمعاينة المحلية ولعرض الطلبات السابقة. بيانات المنتجات الحقيقية لا تجعل إتمام الطلب أو الدفع أو تسجيل الدخول فعليًا؛ لا توجد استدعاءات إنشاء طلب أو دفع. رسوم التوصيل والضرائب وكود DEMO10 ما زالت منطق معاينة محليًا. يلزم تأكيد الأسعار وحساب الرسوم والخصومات على الخادم عند ربط واجهة إنشاء الطلب.

دوال الطلبات وواجهات الاستجابات موجودة في lib/api/shiny-carpet.ts وlib/api/types.ts. رابط API ثابت داخل الكود ولا يعتمد على .env. الطلبات GET مع Accept: application/json وAccept-Language: ar، وبمهلة ١٠ ثوانٍ وإلغاء الطلب عند تغيير الصفحة أو التصنيف.
